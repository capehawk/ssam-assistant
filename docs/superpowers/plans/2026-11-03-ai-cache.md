# 채점 AI 요청 손보기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 채점 세 곳(평가지·단원평가·활동지)과 검토 AI가 공통 부분을 앞에 두고 캐시하게 하고, 단원평가·활동지 동시 채점을 3→4명으로 늘리며 한도에 걸려도 멈추지 않게 하고, 채점 뒤 사용량 한 줄을 보인다.

**Architecture:** 회사별 요청 모양·사용량 읽기는 새 순수 모듈 `core/ai-wire.js`, 늘고 주는 일꾼은 `core/ai-pool.js`. `core/ai.js`가 `ai-wire`를 `window.SSAM_WIRE`로 내놓고, 옛 IIFE `evaluate.js`의 `callApi`·`generate`가 그것으로 내용을 짜고 사용량을 `meter`에 더함. 채점 프롬프트는 공통(shared)/학생(own)으로 나눔.

**Tech Stack:** 정적 ES 모듈(web/), 옛 IIFE `menus/evaluate/evaluate.js`(window.SSAM), node:test, Playwright e2e(`tests/e2e/*.mjs`, helpers `open/run/assert/mockClaude`).

**Spec:** `docs/superpowers/specs/2026-11-03-ai-cache-design.md`

- 공통 부분은 같은 채점 안에서 글자 하나도 다르지 않게: 학생 번호·쪽 수·검토할 문항은 모두 학생 글(own).

- 사용량 문구: `AI 사용량: 보낸 양 약 4.2만 토큰(그중 83%는 캐시로 싸게) · 받은 답 9,120 토큰`. 1만 이상은 「약 n.n만」(소수 .0이면 뺌), 1만 미만은 쉼표 숫자. 캐시 0이면 괄호 뺌. 모두 0이면 빈 글.

1. 학생마다 쪽 수가 다를 때(1쪽·2쪽) 공통 글이 달라지면 캐시가 깨짐 → 공통은 같아야 함(Task 4·5 단위 시험).
