# 업무별 AI와 검토 AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 업무(채점·평어·계획·피드백)마다 메인 AI를 고르고, 켜면 검토 AI가 필요한 곳만 다시 봐서 다르면 두 의견 중 선생님이 고르게 한다.

**Architecture:** `core/ai-roles.js`가 업무별 설정(`ai-roles`)과 `pick(task, role)`·메뉴의 AI 줄을 맡고, `core/ai.js`·옛 `evaluate.js`의 `generate`가 `{ task, role, use }`로 그 AI를 부른다. `core/ai-review.js`는 검토 프롬프트·답 읽기·같은지 판정·두 의견 HTML(순수 함수)과 `reviewJSON`(검토 AI가 없으면 `null`, 실패하면 `{ error }`)을 둔다. 각 메뉴는 메인 결과 뒤 필요한 곳만 골라 `reviewJSON`을 부르고 결과를 `rv`로 저장·표시한다.

**Tech Stack:** 정적 ES 모듈 + 옛 classic script(`window.SSAM`), node:test, Playwright e2e(`tests/e2e/helpers.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-02-ai-roles-design.md`

## Global Constraints

- 업무 키: `grade` 채점 · `writing` 평어·행특·창체 · `plan` 계획 초안 · `notes` 피드백·알림. 그 밖은 task 없음(기본 AI, 검토 없음).
- 저장 키 `ai-roles`(GLOBAL): `{ review: AI|null, tasks: { [task]: { main: AI|null, reviewOn: bool, review: AI|null } } }`, AI = `{ engine, model }`, engine ∈ claude·gemini·openai·upstage. 키는 넣지 않음.
- 키를 넣은 회사만 고름. 키가 없어진 AI는 없는 것으로(기본으로). `account` 엔진이면 업무별·검토 없음.
- 처음엔 모든 업무의 검토가 꺼져 있고 동작은 지금과 같음.
- 검토 AI에 보내는 것 = 메인에 보내는 것과 같은 범위(이름 가린 그림, 번호·점수, 이름 없는 글).
- 검토 실패는 일을 막지 않음: 메인 결과 그대로, 「검토하지 못했어요」, 그 차례의 남은 검토는 그만둠.
- 두 의견: 노란 표시 + 「검토 의견」, [검토 안 쓰기] [그대로 두기]. 고르기 전 메인 안 그대로. 손으로 고치면 검토 의견 사라짐.
- 문구: 쉬운 우리말(앱의 다른 문구와 같은 말투), 사용량 안내 「검토를 켜면 AI 사용량이 대략 1.2~1.5배예요」, 두 회사 안내 「학생 답안 그림(이름 가림)이 두 회사로 가요」.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, `Claude-Session: https://claude.ai/code/session_01KjeihiYexWK2nFymBR9ht6`.

## Review Focus

1. 업무에 정한 회사의 키를 나중에 지움 → 그 업무는 기본 AI로 부르고 AI 줄에 「키가 없어 기본 AI로」 (Task 1 단위 시험, Task 2 화면 시험).
2. 검토 AI가 401·한도로 실패 → 메인 채점 결과·노란 칸 그대로, 「검토하지 못했어요」, 같은 채점 차례의 다음 학생은 검토 요청 안 함 (Task 4).
3. 두 의견이 있는 칸·문장을 선생님이 손으로 고침 → 검토 의견 사라짐 (Task 4, Task 7).
4. 같은 학생을 다시 채점 → 지난 검토 의견은 지우고 새 검토만 보임 (Task 4).
5. `account` 엔진(claude.ai 안) → AI 줄은 「Claude 계정 하나로」, 검토 요청 없음 (Task 1 단위 시험).
