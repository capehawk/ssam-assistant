# 공문 처리 · 회신서 모으기 · 본문 표 · 양식 잇기 설계

날짜: 2026-11-04 · 대상 버전: 0.17.0 · 앞선 설계: `2026-11-03-home-letter-design.md`(가정통신문), `2026-11-03-report-edufine-design.md`(결과 보고)

## 1. 정한 것 (선생님 답)

| 질문 | 답 |
|---|---|
| 공문 처리 자리 | **새 탭 「공문 처리」**(기타 › 공문 처리). 공문을 넣으면 AI가 제출 기한·할 일을 뽑고, [쪽지][가정통신문][품의][결과 보고]로 그 공문을 들고 넘어감. 목록은 기한 차례, 할 일은 체크. 「쌤」 버튼에 놓은 공문도 여기로 |
| 기한 보이기 | **학사일정(달력)**, **학급 › 오늘 수업 화면 위**, **공문 처리 목록** |
| 회신서 모으기 | **이름 칸 가리고 AI가 읽기**: 가리기 편집기로 이름 칸을 한 번 가리면, AI는 번호와 ☑ 표시만 읽음. 못 읽은 칸은 노랗게, 선생님이 고침 |
| 본문 표 | **본문에 「|」로 칸 나눈 줄**: 「| 시간 | 내용 |」 줄이 이어지면 표. AI도 이렇게 씀. 본문 아래 표 미리보기 |

## 2. 미뤄 둔 작은 것 (0.16 최종 검토에서 미룸)
- 결과 보고: 다시 열면 사진 설명이 어긋남(사진은 화면에만 있으니 다시 열면 설명도 비움), 최근 목록 크기(20개·글 길이 줄임), 학년도는 `getSchool().year`, `guessSourceKind`는 학년도로 「작년」을 가리고 공문 표시(「문서번호」·「수신」)를 먼저 봄, 사진 주소(objectURL) 새는 것·읽는 중 다른 보고를 열면 옛 보고에 넣는 것.
- 쪽지: 버튼 위에 마우스만 올려도 저장되던 것(누를 때만), 같은 파일을 60초 안에 다시 놓으면 무시하던 것(같은 끌어 놓기 한 번만 거름).
- 가정통신문: 대체 단계 문단은 선생님이 쓴 앞 공백을 따름, 글 바꿀 때 첫 글 조각의 글자 모양(`charPrOf`), 양식 고르기가 겹치면 마지막 것만(차례 번호), IndexedDB·채우기·저장 실패 알림(꽉 참 안내), 이번에만 쓰는 큰 양식이 탭을 다시 열면 사라지던 것, 회신서(테두리를 더할 수 없으면 알림·칸은 보통 문단 모양·단 나눔 지움), 미리보기 그림·`opf:title`.
- 시험 이름 「업무 6개」 → 실제 수.

## 3. 본문 표 (가정통신문·결과 보고 공통)
- **꼴**: 본문 줄이 `|`로 시작하고 `|`로 끝나면 표 줄. 이어진 표 줄 묶음 = 표 하나. 첫 줄은 머리(굵게). `|---|---|` 같은 줄은 버림. 칸 수는 가장 긴 줄에 맞추고 모자란 칸은 빈칸.
- `parseTableLines(lines) -> [{ type: 'line', text } | { type: 'table', rows }]`(`web/core/body-table.js`, 화면 없이).
- **hwpx 양식**(`fillForm`): 표 묶음은 문단 하나에 표(칸 너비는 글 폭을 칸 수로 나눔, 테두리는 회신서와 같은 실선을 header.xml에 한 번만 더함). 칸은 모두 본문 보통 모양(양식마다 굵은 글자 모양 번호가 달라 머리 칸도 보통 모양, 표 머리 줄로 표시). 테두리를 더할 수 없으면 표 줄을 글 그대로(「a | b」) 두고 `warn: 'no-border'`.
- **기본·.hwp 양식**(`plainLetterDoc`): `{ type: 'table', head: true, rows }` 블록.
- **AI**: 「시간표·준비물처럼 칸이 있는 내용은 `| 시간 | 내용 |` 줄로(첫 줄은 머리)」.
- **화면**: 본문 칸 아래 표 미리보기(표 줄이 있을 때만).

## 4. 양식 잇기
### 4.1 행사계획 → 가정통신문
- 행사계획 › 문서 세트 › 가정통신문 칸에 **[학교 양식으로]**: 기타 › 가정통신문으로 가서 새 가정통신문의 결과 칸에 제목(「행사명 안내」)·본문(줄 그대로)을 넣음(AI 안 부름). 발행일 오늘, 회신서 끔. 고른 학교 양식으로 바로 내려받기.
- `putLetterDraft({ title, body: [줄], memo })`.

### 4.2 결과 보고서 → 학교 양식
- 결과 보고 탭 내보내기 줄에 **양식 고르기**(저장한 .hwpx 양식, 가정통신문과 같은 저장소). 고르면 [한글로 내려받기]가 `fillForm`으로.
- 결과 보고서 문서 → 양식 글: `docToLetter(doc) -> { title, body: [줄], photos }` — 제목 블록 `h`는 그 줄, `p`는 줄마다, 표는 `|` 줄, `c`는 그 줄, 사진은 `photos`(본문 끝에 2열 사진 표: 칸마다 사진·설명).
- 결과 보고용 자리 검사 `rolesValid(r, { date: false })`: 제목·본문만 있으면 됨(날짜가 있으면 오늘 날짜로 바꿈). 맞지 않으면 「기타 › 가정통신문 › 양식 맞추기에서 자리를 정해 주세요」.
- 사진: `BinData/ssam_img<n>.jpg`, `content.hpf`의 manifest에 항목을 더함(이미 있는 이름과 겹치지 않게).

## 5. 기타 › 공문 처리 (탭 id `gongmun`)
### 5.1 넣기
- 공문 파일(한글·PDF·워드·글, 여러 개 → 파일마다 하나씩) 끌어 놓기·고르기, 또는 글 붙여 넣기. 글은 `cleanSheet`로 명단·전화번호 줄을 빼고 AI로. 원본 파일은 저장하지 않음(글만, 8천 자까지).
- AI 한 번(업무 `gongmun` 「공문 처리」, 검토 없음): `{ title, from, no, date, due, dueNote, summary, tasks: [{ text, due }], kinds: ['message'|'letter'|'purchase'|'report'] }`. 날짜는 `YYYY-MM-DD`(학년도·오늘 날짜를 줘서 연도를 채움), 기한을 모르면 빈칸. 할 일 6개까지.
- AI가 없거나 실패하면 제목(파일 이름)·글만 넣고 기한은 선생님이 적음.

### 5.2 목록 (`gongmun:list`, 학년도 자료, 40개까지)
- 문서 `{ id, name, title, from, no, date, due, dueNote, summary, tasks: [{ text, due, done }], kinds, text, at, done }`.
- 차례: 끝나지 않은 것 → 기한 가까운 것 먼저(기한 없는 것은 뒤) → 넣은 차례. 끝난 것은 접어서 맨 아래.
- 줄마다: D-n 표시(지남·오늘·D-1~3은 빨강·주황), 제목·발신·문서번호, 요약, 할 일 체크(체크하면 줄 긋기), 기한·할 일 고치기, [다 했어요], [지우기], 넘기기 버튼 4개(AI가 고른 것은 강조).
- 넘기기:
  - [쪽지] → `putMessageFiles([], { text })`.
  - [가정통신문] → `putLetterSources({ sources: [{ name, text }] })`(넣기 칸에 공문을 넣고 「넣을 내용」은 비움).
  - [품의] → `putPurchaseText(text)`(새 품의 한 칸에 넣고 바로 초안).
  - [결과 보고] → `putReportSources({ sources: [{ kind: 'official', name, text }] })`.

### 5.3 기한 보이기
- 학사일정: `setEvents('gongmun', …)` — 끝나지 않은 문서의 기한(「[제출] 제목」)과 기한 있는 할 일(「[할 일] 할 일」, 끝난 할 일은 빼고).
- 오늘 수업: 화면 맨 위에 「공문 기한」 띠 — 오늘부터 7일 안(지난 것 포함, 끝나지 않은 것) 3개까지 「D-2 ○○ 제출」, 누르면 기타 › 공문 처리.
- 「쌤」 버튼: 안내·공문 파일(`notice`)은 기타 › 공문 처리로(그 뒤 쪽지 등은 버튼으로).

## 6. 회신서 모으기 (가정통신문 탭, 회신서를 붙인 가정통신문)
- 회신서 칸 가운데 □가 있는 칸만 읽음(예: 「참가 여부: □ 참가 □ 불참」 → 선택지 참가·불참). □가 없는 칸(연락처 같은 것)은 읽지 않음.
- 스캔(PDF·사진 여러 장) 넣기 → 쪽마다 하나 → **[이름 칸 가리기]**(가리기 편집기, 첫 쪽들 보기). 가리지 않으면 읽기 전에 가리게 함(가린 칸이 없으면 읽지 않음).
- 읽기: 쪽마다 가린 그림을 AI로(업무 `reply` 「회신서 읽기」, 동시에 몇 장): `{ no: 번호|null, answers: { 칸: 선택지|'' }, unsure: [칸] }`. 학년·반은 읽지 않고 번호만.
- 표: 번호 차례, 번호 × 칸. 못 읽은 칸·번호가 없거나 겹치는 줄은 노랑, 칸을 눌러 고름. 아래: 칸별 선택지 수, **미제출 번호**(설정 › 명단의 번호 중 빠진 것, 명단이 없으면 1~가장 큰 번호).
- 복사(탭으로 나눈 글), 한글·워드·PDF로 내보내기. 저장: 가정통신문 자료에 `collect: { mask, rows: [{ no, answers, unsure }] }`만(그림·이름은 저장하지 않음).

## 7. 지키는 것
- 학생 이름은 저장하지 않고 AI로 보내지 않음(회신서는 이름 칸을 가린 그림만).
- 원본 공문 파일은 저장하지 않음. 명단·전화번호 줄은 빼고 AI로.
- 저장·결재·상신은 앱이 누르지 않음.

## 8. 시험
- 단위: `body-table`, `hwpx-form` 표·사진·보고 자리, `docToLetter`, `gongmun-ai`(프롬프트·정리·차례·D-n·일정), `reply-collect`(선택지·정리·집계·미제출), 미뤄 둔 것들.
- e2e: 공문 처리(넣기·AI 흉내·목록·체크·넘기기 4개·달력·오늘 수업 띠), 가정통신문 표 미리보기·행사계획 잇기, 결과 보고 양식 내보내기, 회신서 모으기(가리기·읽기 흉내·표·미제출).
