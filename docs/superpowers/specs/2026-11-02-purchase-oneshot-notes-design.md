# 품의 「한 칸 → 바로 초안」 · 기타 › 쪽지 작성 설계

날짜: 2026-11-02 · 대상 버전: 0.13.0 · 앞선 설계: `2026-10-31-purchase-complete-design.md`(품의), `2026-10-30-inbox-button-design.md`(떠 있는 버튼)

## 1. 정한 것 (선생님 답)

| 질문 | 답 |
|---|---|
| 품의 화면 | 기본은 **「한 칸 → 바로 초안」**. 설정에서 **「빠진 것만 AI가 물어보기」**로 바꿀 수 있게 |
| 품의 필수 칸 | 일시·대상은 필수 아님. 필수는 **목적·품목 1개**(목적은 비면 AI가 짐작) |
| 쪽지 프로그램 | 충남교육청 **「이음」** 메신저. 쪽지 모양·붙임 넣는 방법을 알 수 없으므로 어디에나 붙는 **보통 글** |
| 붙임 파일 | 쪽지 끝에 **붙임 목록** + Windows 앱은 **[붙임 파일 복사]**(쪽지 창에 Ctrl+V)와 **[폴더 열기]**(끌어 놓기). 웹판은 목록만 |
| 쪽지 내용 | 공문·계획에 **있는 것만** 그때그때: 일시·장소·대상, 신청·회신 기한과 방법, 준비물·유의 사항, 문의(보내는 사람) |
| 떠 있는 버튼 | 일시·장소·대상·신청이 있는 **안내 공문·계획은 「쪽지로 안내하기」가 기본**. 지침·운영 계획은 지금처럼 「계획에 지침으로 넣기」. 카드에서 바꿀 수 있음 |
| 쪽지 모양 | **짧은 안내 + [자세히]·[더 짧게]** |
| 쪽지 기록 | **최근 쪽지 20개**(붙임 파일은 남기지 않고 이름만) |

## 2. 있는 부품 (다시 씀)

- 품의: `menus/purchase/intake.js` `readIntake`(글·엑셀·견적서·캡처 → 품목·칸), `rules.js` `checks`·`composeReason`·`reasonTail`, `purchase.js`의 초안(`draftPrompt`·`makeDraft`)·템플릿·최근 작성·검토 AI.
- 글 읽기: `core/files.js` `readText`(한글·PDF·엑셀·CSV·txt), 사진·글자 없는 PDF는 `SSAM.files.readPages` + AI 그림 읽기.
- 개인정보: `core/privacy.js` `stripNames`(명단 줄·전화번호 줄 빼기, 직책 옆 이름 ○○○).
- 떠 있는 버튼: `core/inbox-classify.js` `KINDS`·`classify`, `core/inbox.js` `registerInbox`, 카드의 「할 일」 고르기.
- 업무별 AI: `core/ai-roles.js`(업무 `purchase`, 새 업무 `note`).
- Windows 앱: `src-tauri/src/files.rs` `save_download`, `tauri-plugin-opener`, `arboard`(클립보드, Windows `file_list` 쓰기 지원).

## 3. 품의 — 한 칸 → 바로 초안

### 3.1 처음 화면 (「간단히」, 기본)
- 위에서부터: 종류(물품 구입·강사 수당·행사 운영·협의회), **큰 넣기 칸 하나**(파일·캡처·붙여넣기·끌어 놓기·대충 쓴 글), **[초안 만들기]** 하나.
- 넣기 칸 안내 예: 「예) 3학년 과학 실험 알코올램프 10개 5,000원, 다음 주 화요일 과학실」.
- 다른 칸(사업명·목적·일시·대상·장소·총액·예산 과목·품목 줄·계산 도우미·붙임·메모)은 **[자세히 고치기]**를 눌러야 펼쳐짐. 펼침 여부는 기억(`purchase:view` = `'simple'|'full'`).
- 템플릿·최근 작성에서 연 품의는 지금처럼 메모가 채워진 채로 보이고, 초안이 있으면 초안을 보임.

### 3.2 [초안 만들기] 한 번에
1. 넣기 칸에 글·파일이 있으면 먼저 `readIntake`로 넣음(이미 쓴 칸은 덮지 않음, 품목이 있으면 더하기). 넣기 칸이 비고 메모도 비면 「넣기 칸에 사려는 것·견적서를 넣어 주세요」.
2. **종류 짐작**: 선생님이 종류를 누르지 않았으면 넣기 AI 답의 `type`(goods·lecturer·event·meeting, 글에 드러날 때만)으로 바꿈. 강사 수당으로 바뀌면 그 뒤로는 강사 규칙(넣기 칸 글·그림을 AI로 보내지 않음)을 따름. 강사 수당은 넣기를 앱 규칙으로만 읽으므로 짐작하지 않음.
3. **목적 짐작**: 목적이 비어 있으면 초안 AI가 품목·사업명·넣은 글에서 목적을 한 문장으로 함께 씀(`purpose`). 칸에는 넣고 「AI가 짐작함」 표시.
4. 확인 목록(`checks`)의 필수는 **목적·품목 1개**만. 일시·대상·장소가 비면 품의 사유에서 그 줄을 빼고 가·나·다를 다시 매김(`composeReason`).
5. 초안(제목·품의 사유·산출 내역)을 바로 보이고, 그 위에 **「확인할 것」 칩**만 노랗게:
   - 예산 과목이 비었으면 「예산 과목 · 행정실 확인」(추천 칩 함께)
   - 단가·수량이 빈 품목 「단가 없는 품목 n개」
   - 목적을 AI가 짐작했으면 「목적 · AI가 짐작함」
   - 일시·대상이 비었으면 「일시·대상 없이 썼어요」(정보, 노랑 아님)
   - 지금의 경고(합계와 총액 다름·계약 기준 금액 넘음·협의회 상한 등)
   - 칩을 누르면 [자세히 고치기]가 펼쳐지고 그 칸으로 감.
6. 개인정보(주민번호·계좌)는 지금처럼 막음.

### 3.3 「빠진 것만 물어보기」 모드
- 설정 › 품의 기준 › **넣는 방식**: 「바로 초안 (기본)」 / 「빠진 것만 물어보기」(`purchase:flow` = `'oneshot'|'ask'`).
- 넣은 뒤 초안에 꼭 필요한데 없는 것만 **최대 2개** 작은 창으로 물어봄: 목적이 없으면 「무엇에 쓰나요?」, 품목이 없으면 「무엇을 얼마나 사나요? (예: 색종이 10묶음 3,000원)」(답은 앱 규칙으로 품목 줄). 없는 것이 없으면 바로 초안.
- 물어본 창을 닫으면 초안을 쓰지 않고 넣은 것만 남김.

### 3.4 떠 있는 버튼 「견적서」
- 새 품의에 넣은 뒤 AI가 되면 **초안까지** 씀(3.2). 지금 쓰는 품의가 있으면 지금처럼 「더하기/새 품의로」를 물음.

## 4. 기타 › 쪽지 작성

### 4.1 메뉴
- 세로 메뉴 「기타」(설정 위, 아이콘 `etc`), 가로 메뉴 **[쪽지 작성]** 하나. 화면 파일 `web/menus/etc/note.js`.

### 4.2 넣기
- 넣기 칸 하나: 공문·연수 계획·행사 계획 파일 여러 개(한글·PDF·사진·txt·hwpx) 또는 붙여 넣은 글.
- 글은 `readText`, 사진·글자 없는 PDF는 쪽 그림을 AI가 읽음(이름 칸 가림 없음 — 공문이므로. 대신 아래 개인정보 규칙).
- **개인정보**: AI로 보내기 전에 `stripNames`(명단 줄·전화번호 줄 빼기, 직책 옆 이름 ○○○)와 주민번호 줄 빼기. 뺀 줄 수를 알림.
- 넣은 파일은 모두 **붙임 후보**(체크로 빼기·순서 바꾸기). 이름은 확장자를 뺀 파일 이름(고칠 수 있음).

### 4.3 AI가 찾는 것 (업무별 AI 「쪽지」)
- 프롬프트 머리 `[쪽지 안내]`. 답 JSON:
  `{ kind: 'training'|'meeting'|'event'|'submit'|'etc', title, when: [{ date: 'YYYY-MM-DD', time: '', note: '' }], place, target, apply: { due: 'YYYY-MM-DD', how: '' }, bring, notes, points: ['…'] }`
- 글에 없는 것은 빈칸(지어내지 않음). 연도가 없으면 앱이 지금 학년도로 채움. `points`는 주요 내용 최대 5줄.

### 4.4 쪽지 글 (앱이 맞춤)
- 제목: `[연수 안내]`·`[회의 안내]`·`[행사 안내]`·`[제출 안내]`·`[안내]` + 제목.
- 본문(짧게·기본·자세히 — 앱이 고름, AI를 다시 부르지 않음):
  ```
  선생님들, 안녕하세요.
  ○○ 연수를 아래와 같이 안내드립니다.

  □ 일시: 2026. 11. 12.(목) 15:00~16:30
  □ 장소: 시청각실
  □ 대상: 전 교직원
  □ 신청: 2026. 11. 7.(금)까지 이음 쪽지로 회신
  □ 준비물·유의 사항: 개인 노트북 지참
  □ 주요 내용 (자세히일 때)
    - …

  붙임  1. ○○ 연수 계획 1부.
        2. ○○ 공문 1부.  끝.

  문의: 교무부 ○○○(내선 123)
  감사합니다.
  ```
- 있는 것만 넣음(없는 줄은 뺌). 날짜는 학교 공문 꼴 `2026. 11. 12.(목)`, 요일은 앱이 셈. 일시가 여러 개면 한 줄씩.
- 짧게: 일시·장소·대상·신청만, 기본: + 준비물·유의 사항, 자세히: + 주요 내용.
- **보내는 사람(문의)**: 화면에 한 번 적어 두면(`note:sender`, 학년도와 상관없이) 늘 끝에 붙임. AI로 보내지 않음.
- 칸 고치기: 제목·일시·장소·대상·신청·준비물을 표로 고치면 본문이 다시 맞춰짐. 본문을 손으로 고치면 그대로 두고 [다시 맞추기].
- 단추: [제목 복사]·[본문 복사]·[모두 복사].

### 4.5 붙임 파일 (Windows 앱)
- **[붙임 파일 복사]**: 붙임 후보(체크한 것)를 `다운로드/쌤비서 쪽지 붙임/<날짜> <제목>/`에 저장하고 그 파일들을 클립보드에 파일로 넣음(탐색기에서 Ctrl+C 한 것처럼). 「이음 쪽지 창의 첨부 칸에서 Ctrl+V 해 보세요. 안 되면 [폴더 열기]로 끌어 놓으세요」.
- **[폴더 열기]**: 같은 폴더를 저장(없으면)하고 탐색기로 엶.
- Rust 명령: `note_save_attachments(folder, files: [{name, bytes}]) -> 경로`(같은 이름은 `(2)`), `note_copy_files(paths)`(arboard `file_list`), 열기는 opener `reveal_item_in_dir`/`open_path`.
- 웹판: 붙임 목록만 쓰고 「Windows 앱에서는 파일 복사·폴더 열기가 돼요」.

### 4.6 최근 쪽지
- 쪽지 작성 아래 **최근 쪽지 20개**(`note:list`, 학년도 자료): 날짜·제목·종류. [열기]로 그 쪽지(칸·본문·붙임 이름)를 다시 엶. [다시 안내]: 제목을 `[다시 안내]`로 바꾸고 첫 줄을 「다시 한번 안내드립니다.」로. 붙임 파일은 남기지 않음(이름만, 복사·폴더 열기는 파일을 다시 넣어야).

## 5. 떠 있는 버튼 「연수·행사 안내」
- `KINDS`에 `['notice', '연수·행사 안내', '쪽지로 안내하기']`(지침 `guide` 앞).
- `classify`: 머리(앞 15줄)에 연수·회의·협의회·설명회·행사·대회·신청·참가·모집·안내 중 하나가 있고, 글에 일시·장소·대상·신청(기간)·참석 중 **둘 이상**이 있으면 `notice` 8점. 지침·계획서 표시(목적·방침·세부 추진 계획 둘 이상, 「지침」 제목)가 더 강하면 그대로 `guide`·`year-plan`.
- `registerInbox('notice')` → 기타 › 쪽지 작성에 그 파일들을 넣고 AI가 되면 바로 쪽지까지. 떠 있는 버튼으로 넣은 파일도 붙임 후보.

## 6. 저장·개인정보·AI
- 저장 키: `purchase:view`·`purchase:flow`·`note:sender`(화면 취향·보내는 사람 — `years.js` `GLOBAL`에 더해 학년도와 상관없이), `note:list`(학년도 자료, 20개), `note:draft`(지금 쓰는 쪽지, 학년도 자료). 백업 파일에는 지금처럼 모두 들어감(AI 키는 빼고).
- AI로 보내는 것: 품의는 지금 규칙 그대로(강사 수당은 넣기 칸 글·그림을 보내지 않음, 이름 ○○○). 쪽지는 명단·전화번호 줄을 뺀 공문 글·쪽 그림만. 보내는 사람·붙임 파일 내용은 보내지 않음(파일 이름은 앱이 붙임 목록에만 씀).
- 업무별 AI: `note`(쪽지) 업무를 더함(기본 AI를 씀, 검토 AI 없음).

## 7. 시험
- 단위: `rules` 필수(목적·품목만)와 일시·대상 없는 사유의 가·나·다; 넣기 답 `type` 다듬기; 쪽지 AI 답 다듬기(`normNotice`)·쪽지 글 맞추기(`composeNote` 짧게·기본·자세히, 날짜 요일, 없는 줄 빼기, 붙임 번호·「끝.」, 문의); `classify` 안내 공문 → `notice`, 지침·운영 계획은 그대로.
- 화면: 품의 간단히 → 글 한 줄 넣고 [초안 만들기] → 초안·확인할 것 칩(가짜 AI), [자세히 고치기]; 빠진 것만 물어보기 모드; 쪽지 작성(지어낸 연수 공문 txt + 계획 파일) → 쪽지 글·복사·붙임 목록·최근 쪽지·다시 안내; 떠 있는 버튼 안내 공문 → 카드 「연수·행사 안내」 → 쪽지.
- Rust: `note_save_attachments` 이름 겹침 `(2)`·안전한 폴더 이름(`cargo test`).
- 예시 파일: `samples/연수안내-공문-예시.hwpx`(지어낸 것).

## 8. 하지 않는 것
- 이음 메신저로 직접 보내기·받는 사람 고르기(이음 연동 정보가 없음).
- 쪽지 붙임 파일 내용 읽어 요약 외의 일(붙임 파일을 고치거나 묶지 않음).
- 품의 AI가 산출 내역 금액을 정하는 것(금액은 지금처럼 앱이 계산).
