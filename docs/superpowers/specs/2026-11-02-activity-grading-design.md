# 활동지 평가 · 한꺼번에 넣기 설계

날짜: 2026-11-02 · 요청: 「평가쪽에서 수업중, 수업후 활동지도 넣으면 평가하는 기능도 넣어줘. 대신 활동지는 답안지가 없거나 예시답안, 그림, 주관식이 대부분이니깐 그걸 생각해서 기능을 구현해주고. 그리고 답안과 평가지를 따로 넣지 않고 같이 넣어도 알아서 구분해서 평가하는 기능을 단원평가, 수행평가, 활동지 평가에도 구현해줘」

## 1. 정한 것 (선생님 답)

- 「같이 넣기」는 **둘 다**: 한 파일 안의 학생용·교사용(예시·정답) 쪽 나누기 + 학생 답안 스캔과 정답지·문제지를 한 번에 넣어도 종류 나누기.
- 활동지 결과(모두): 문항별 **○(잘함)·△(조금 더)·×(틀림)·안 함(빈칸)**, 학생별 짧은 피드백(잘한 점·더 해 볼 점), 잘함·보통·노력 수준, 교과 평어에 참고할 수 있는 기록.
- 정답·예시 답안이 없으면 **AI가 기준을 먼저 만들고 선생님이 확인**한 뒤 같은 기준으로 채점.
- 그림 문항: **AI가 표현 정도(자세함·정성)까지** 봄.
- 자리: **평가 › 새 탭 「활동지」**.
- 수준(잘함·보통·노력): **AI가 판단**(까닭 함께), 선생님이 바꿀 수 있음.
- 한꺼번에 넣은 것을 앱이 나누면 **나눈 결과를 보여 주고 확인한 뒤** 채점.
- 틀린 답(고르기·짝짓기·빈칸)은 △가 아니라 **×**.
- 스캔 안 정답·교사용 쪽 찾기: **앞 2쪽·뒤 2쪽**을 봄(글자층이 있으면 글자층으로).
- 교과 평어 참고: 단원평가·활동지마다 「교과 평어에 참고하기」 스위치(**기본 꺼짐**) → 켜면 교과는 알아서(바꿀 수 있음)·**평가 영역(평가요소)** 고르기 → **평가지 채점(수행평가)**에서 그 영역에 이어 둔 단원평가·활동지가 목록으로 나오고(최근 5개, [더보기]) **체크한 것만**(기본 체크 안 함) 학생별 평어를 쓸 때 참고.
- 학생별 모아 보기는 교과·**학기**(1학기·2학기)로 거름. 학기는 날짜로 정하고 바꿀 수 있음.
- 「수행평가」 = 지금의 평가 › 평가지 채점 탭.

## 2. 지금 있는 것 (그대로 쓰거나 넓힘)

- 단원평가(`web/menus/evaluate/unit/`): 1단계 정답지·문제지(`unit-key.js` `parseKey`·`parsePaper`·`splitCombined` — 「정답 (및 해설)」 줄로 나눔), 2단계 답안 올리기(`unit-grading.js` `loadAnswers`: `SSAM.files.readPages` → `arrangePages` → 학생당 쪽 수로 나눔, 이름 칸 가리기, 적힌 번호로 맞추기 `core/student-no.js`), 3단계 채점(AI가 답을 읽고 `unit-grade.js` `autoJudge`·`gradeCell`이 정답과 맞춤, 노란 칸 확인), 피드백·결과·「교과 평어 초안」.
- 평가지 채점(`evaluate.js` GR): 스캔 → 학생별 → 이름 가리기 → 채점(채점 기준 글·그림·한글 정답표 `critDocs`·`critImgs`) → 비율대로 수준 → 학생별 평어(`GR.unitId` = 평가계획의 평가요소, 평어 프롬프트 `[학생]` 줄).
- 평가계획: 교과 평어 탭이 넣은 `S.plan.subjects[].units[]`(`{ id, subject, area, elem, unit, std, crit }`), 저장 `ssam:plan:<id>`.
- 업무별 AI(`core/ai-roles.js`) 「채점」, 검토 AI(`core/ai-review.js`), 떠 있는 버튼 종류 판단(`core/inbox-classify.js` KINDS), 내려받기(`core/doc-export.js`), 개인정보 줄 빼기(`core/privacy.js`).

## 3. 한꺼번에 넣기 (공통 부품 `web/core/bundle.js`)

세 곳(활동지·단원평가·평가지 채점) 맨 위 「한꺼번에 넣기」 칸에 파일 여러 개를 한 번에 넣음.

### 3.1 나누는 차례

1. **파일별**: 글이 있는 파일(한글 .hwp·.hwpx, 글자층이 있는 PDF, .txt) → 「문서」, 사진·글자층 없는 PDF → 「스캔」.
2. **문서 안**: 학생용(문제지·빈 활동지)과 교사용(정답·예시 답안·채점 기준)을 나눔.
   - 나누는 표시: 줄 머리의 「교사용」, 「(예시)」·「예시 답안」·「예시답안」, 「[정답]」·「정답」·「정답 및 해설」, 「모범 답안」, 「채점 기준」. 이름 칸 줄에 붙은 「교사용」(예: 「이름: 교사용」)도 표시로 봄.
   - 같은 머리(첫 줄·제목 줄)가 다시 나오면 그 앞에서 나눔(학생용 쪽 다음에 같은 양식의 교사용 쪽이 붙은 파일).
   - 표시가 없으면 한 덩어리(학생용)로 봄. 정답 표만 있으면 교사용만.
   - 단원평가의 `splitCombined`는 이 나누기를 씀(지금 「정답」 줄 규칙은 그대로 통과).
3. **스캔 안**: 정답·교사용·빈 활동지 쪽과 학생 쪽.
   - PDF 쪽에 글자층이 있으면(인쇄본을 그대로 PDF로 만든 쪽) 문서 쪽으로, 없으면 학생 쪽.
   - 모두 스캔이면 **앞 2쪽·뒤 2쪽**의 작은 그림(긴 변 512px, 이름 칸 가림)을 AI에 한 번 보내 쪽마다 `teacher`(정답·교사용 인쇄)·`blank`(손글씨 없는 빈 활동지)·`student`(손글씨 있는 학생 쪽)를 받음. AI가 없거나 실패하면 모두 학생 쪽으로 두고 카드에서 고치게.
4. **확인 카드**: 쪽 작은 그림을 한 줄로 늘어놓고 「정답·교사용」·「빈 활동지」·「학생」 표시. 쪽을 누르면 표시가 바뀜. 문서도 「학생용 1쪽 · 교사용 1쪽으로 나눴어요」로 보이고 [나누지 않기]로 되돌림. [이대로 넣기]를 눌러야 넣음.

### 3.2 곳마다

- **활동지**: 학생용 → 빈 활동지(문항 찾기), 교사용 → 예시 답안·기준, 스캔의 교사용·빈 쪽 → 기준을 만들 그림, 학생 쪽 → 3단계 학생 활동지.
- **단원평가**: 교사용 → 정답지, 학생용 → 문제지, 학생 쪽 스캔 → 2단계 답안(1단계에서 넣었으면 2단계로 가며 그대로 올라감).
- **평가지 채점**: 교사용·정답 문서 → 채점 기준 문서(`critDocs`), 교사용 스캔 쪽 → 채점 기준 그림(`critImgs`), 학생 쪽 → 학생 평가지.
- 정답·교사용 쪽은 채점 기준으로만 쓰고 학생으로 세지 않음.
- 떠 있는 버튼으로 여러 파일을 넣고 활동지·단원평가·평가지 채점을 고르면 같은 나누기를 거침.

## 4. 활동지 탭 (평가 › 활동지, `web/menus/evaluate/activity/`)

목록: 활동지가 차시마다 쌓임(교과·단원·차시·활동 이름·날짜·학기·채점 상태). [새 활동지]·[예시로 채우기]·[학생별 모아 보기].

### 4.1 1단계 활동지 넣기

- 한글·PDF·사진 활동지 또는 한꺼번에 넣기(3장).
- 머리에서 교과·단원·차시·쪽·활동 이름을 앱이 채움(예: 「[과학] 3-2-4-03 감염병은 왜 위험할까? (94~95쪽)」 → 과학·4단원·3차시·94~95쪽, 「국어 … 1. 경험과 관련지으며 이해해요 | 국어책 32~35쪽」·「[1차시]」). 못 찾으면 빈칸, 선생님이 고침.
- 날짜(오늘)·학기: 학교 정보의 여름방학 끝 다음 날부터 2학기, 없으면 3~8월 1학기·9~2월 2학기. 바꿀 수 있음.
- 활동지 글의 주민번호·전화번호 모양 줄은 `core/privacy.js`로 빼고 알림.

### 4.2 2단계 기준 확인

- 문항 표: 번호 · 종류 · 묻는 말 · 예시 답안 · ○ 기준 · △ 기준 · 출처(「교사용에서」·「정답에서」·「AI가 만듦」·「선생님이 고침」).
- 종류: `choice` 고르기 · `match` 짝짓기(선 잇기) · `short` 빈칸·단답 · `write` 쓰기(주관식) · `draw` 그림·색칠.
- 교사용·정답이 있으면 거기서 문항·예시 답안을 가져오고(글이면 AI 없이 표 줄을 맞추고, 모자란 기준만 AI), 없으면 AI가 빈 활동지(글·그림)를 읽고 문항·예시 답안·○·△ 기준을 만듦(업무별 AI 「채점」).
- 고르기·짝짓기·빈칸은 정답(예시 답안)이 있어야 앱이 맞춤. 정답이 없으면 AI가 만든 정답을 「AI가 만듦」으로 표시.
- [기준 확정] 뒤 모든 학생에게 같은 기준. 고치면 다시 확정하고, 이미 채점한 학생은 「기준이 바뀌었어요 · 다시 채점」.

### 4.3 3단계 학생 활동지 올리기

- 단원평가 답안 올리기와 같은 부품: 반 전체 스캔 PDF·사진, 학생당 쪽 수, 모아찍기·뒷면, 이름 칸 가리기, 적힌 번호로 맞추기, 결석 번호.
- 스캔 안에 교사용·빈 활동지 쪽이 있으면 3.1의 확인 카드.

### 4.4 4단계 채점·확인

- 학생마다 AI 한 번(이름 가린 그림 + 확정한 기준 글, 업무별 AI 「채점」).
- AI 답: 문항마다 `read`(읽은 답 짧게), `mark`(`o`·`t`(△)·`x`·`n`(안 함)), `why`(짧은 까닭), `sure`(확신). 그리고 `good`(잘한 점 한두 문장), `next`(더 해 볼 점 한 문장), `level`(`good` 잘함·`ok` 보통·`try` 노력)과 `levelWhy`.
- 고르기·짝짓기·빈칸은 `read`를 앱이 정답과 맞춰 ○·×(`unit-grade.js` `autoJudge`와 같은 규칙), 빈칸이면 안 함. 쓰기는 ○ 기준을 다 담으면 ○, 일부면 △, 엉뚱하면 ×. 그림은 요구한 것·자세함·정성으로 ○·△(×는 요구와 전혀 다를 때).
- 노란 칸: `sure`가 낮음·앱 판정과 AI가 다름·읽지 못함. 칸을 누르면 ○·△·×·안 함·읽은 답을 고침(고친 칸은 「선생님」).
- 검토 AI(업무별 AI 「채점」 검토를 켰을 때): 노란 칸만 한 번 더(`ai-review.js` 두 의견, [검토 안 쓰기]·[그대로 두기]).
- 수준은 AI 판단, 표에서 바꿀 수 있음. 잘한 점·더 해 볼 점도 고침.

### 4.5 5단계 결과·확정

- 반 표: 번호 × 문항(○·△·×·안 함), 수준, 잘한 점 → 한글·워드·PDF 내려받기·표 복사.
- 학생 피드백 쪽지: 번호·활동 이름·문항 표시·잘한 점·더 해 볼 점, 한 쪽에 4명 → 한글·워드·PDF.
- 문항별 통계: 문항마다 ○·△·×·안 함 수(가장 많이 틀린 문항 먼저).
- [확정]: 학생별 기록으로 남음(학생별 모아 보기·교과 평어 참고에 씀). 확정 뒤 고치면 기록도 바뀜.

### 4.6 학생별 모아 보기

- 번호를 고르면 확정한 활동지가 날짜 차례로: 날짜 · 교과 · 활동 이름 · 수준 · 잘한 점 · 더 해 볼 점. 교과·학기로 거름, [복사].

### 4.7 교과 평어에 참고하기 (단원평가·활동지 공통)

- 활동지 5단계와 단원평가 결과 화면에 「교과 평어에 참고하기」 스위치(기본 꺼짐).
- 켜면: 교과는 활동지·단원평가의 교과로 자동(평가계획의 교과 목록에서 바꿀 수 있음) → 그 교과의 평가 영역(평가요소, `S.plan` units)을 고름. 평가계획이 없으면 「평가 › 교과 평어에서 평가계획을 먼저 넣어 주세요」.
- 저장은 이음만: `link: { unitId, subject, label }`(label = 평가 영역 · 평가요소 글, 평가계획이 바뀌어도 이름으로 찾게).

### 4.8 평가지 채점에서 참고

- 평가요소를 고르면 「참고할 단원평가·활동지」 칸: 그 평가요소(`unitId`가 같거나, 없으면 교과와 label이 같은 것)에 이어 둔 단원평가·활동지를 최근 5개 → [더보기]. 체크 칸, **기본 체크 안 함**. 체크는 그 평가지 채점에 저장.
- 체크한 것만 학생별 평어 프롬프트의 `[학생]` 줄 뒤에 `[참고: 단원평가·활동지]` 줄로 붙임(번호마다): 활동지 「이름」 수준 · 잘한 점 · 더 해 볼 점 / 단원평가 「이름」 점수 % · 잘한 것 · 보완할 것. 한 학생 600자까지.
- 채점·수준에는 쓰지 않고 평어에만.

## 5. 저장·학년도·개인정보·AI

- 저장(학년도 자료): `activity:list`(요약), `activity:a:<id>`(활동지 하나: meta·기준·학생 결과·link·확정), `activity:set`(학생당 쪽 수 등). 평가지 채점의 체크는 GR 본문에 `refs: [id]`. 단원평가의 이음은 시험 본문 `link`.
- 스캔 그림은 저장하지 않음(화면에만, 단원평가와 같음). 백업에 들어가고 새 학년도는 비어서 시작.
- 학생 이름은 저장·전송하지 않음: 이름 칸 가림, 기록·쪽지·표는 번호만. 활동지 예시 답안의 등장인물 이름(쿠키·크림 같은)은 활동 내용이라 그대로.
- AI: 기준 만들기·채점·스캔 쪽 나누기 = 업무별 AI 「채점」, 검토 = 「채점」의 검토 AI.

## 6. 떠 있는 버튼

- 새 종류 `activity`(「수업 활동지」 → 「활동지 평가로 넣기」): 「[N차시]」·「활동」·「교과서 N쪽」·「학년 반 번 이름」이 있고 정답 표(번호-정답 줄 여럿)가 없는 문서.
- 스캔(`unit-scan`)의 받는 곳 고르기에 「활동지 채점」을 더함.

## 7. 예시·시험

- [예시로 채우기]: 지어낸 활동지(과학 「물의 순환 그려 보기」 같은 것)와 학생 결과.
- `samples/활동지-예시.hwpx`(지어낸 것): 학생용 1쪽 + 교사용 1쪽.
- 선생님이 올린 실제 파일은 양식 파악에만 쓰고 레포에 넣지 않음. 시험 자료는 같은 모양으로 지어냄.
- 단위: 나누기(표시·같은 머리·정답 줄·나누지 않음), 머리 읽기(교과·단원·차시·쪽), 학기, 기준 정규화, 채점 답 정규화·앱 판정(○·×·안 함), 수준, 모아 보기, 이음·참고 프롬프트, 떠 있는 버튼 종류.
- 화면: 활동지 5단계(예시 답안 있음·없음, 그림 문항, 노란 칸 고치기, 쪽지 내려받기), 한꺼번에 넣기(문서 하나에 학생용·교사용, 스캔+정답 문서, 스캔 앞쪽 교사용) 세 곳, 단원평가·활동지 이음 → 평가지 채점 체크 → 평어 프롬프트에 참고 줄, 체크 안 하면 없음.

## 8. 하지 않는 것

- 활동지 기록을 교과 평어 탭(수준별 공통 문장)에 자동으로 넣지 않음(평가지 채점에서 체크한 것만).
- 활동지 결과로 평가지 채점의 점수·수준을 바꾸지 않음.
- 스캔 가운데 쪽(앞 2·뒤 2 밖)의 교사용은 찾지 않음(카드에서 선생님이 표시).
