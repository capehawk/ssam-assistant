# 품의 메뉴 완성 설계

날짜: 2026-11-02 · 요청: 「품의 메뉴도 내가 해야 할 것 같아. 진행해줘」 → 「네가 에듀파인 품의 만드는 것을 검색해서 판단해줘」 · 「기본적으로 붙임에 지출품의서 1부 들어가니깐 참고하고 진행해줘」

## 1. 정한 것

- 품의 메뉴는 이제 이 앱에서 직접 만든다(다른 선생님 담당이던 메뉴).
- 선생님이 고른 것: 저장한 템플릿(P-8), 최근 작성(P-9), 종류별 계산 도우미, 업무별 AI에 「품의」 추가.
- 에듀파인에서 손이 많이 가는 곳(선생님이 모두 고름): 산출 내역 표, 품의 사유 문장, 예산 과목, 붙임 서류 → 조사(3장)로 판단해 아래 4장·5장에 넣음.
- 붙임 1번은 늘 「지출품의서 1부」.
- 내려받기 형식 고르기(한글·워드·PDF): 답이 없어 추천대로 넣음(다른 메뉴와 같은 [○○로 내려받기][▾]).

## 2. 지금 있는 것 (그대로 둠)

새 품의 한 화면(왼쪽 메모 → 오른쪽 에듀파인에 붙여넣을 초안), 종류 4개(물품 구입·강사 수당·행사 운영·협의회), 견적서 넣기(엑셀·CSV는 AI 없이, 사진·PDF는 AI), 확인 목록(P-6), 개인정보 막기(P-7), 행사계획에서 [품의로 이어 가기](P-10), 떠 있는 버튼으로 견적서, 설정 › 품의 기준(계약 기준 금액).

## 3. 조사로 알게 된 것 (모든 안내는 「참고용 · 행정실 확인」)

- 에듀파인 품의등록: 제목 → 개요(기안문처럼) → 예산 선택 → 품목내역(품명·규격·**수량 단위**·수량·예상 단가) → 붙임.
- 산출 근거는 금액만 쓰지 말고 「단가 × 수량(× 횟수)」 식이 보이게. 합계 = 견적서 금액. 부가세 포함 여부는 품의와 지출 문서가 같아야 함.
- 예산 과목(원가통계비목)은 학교마다 다르지만 대체로
  - 소모품·인쇄·업무용 도서 → 일반수용비
  - 교구·교육용 재료·학생 활동·학교 행사 → 교육운영비
  - 외부 강사 수당 → 운영수당(지침에 따라 교육강사수당), 교직원 강사 → 기타수당
  - 협의회·간담회·행사성 식비 → 업무추진비(일반수용비로 편법 계상 금지)
  - 오래 쓰는 비싼 물품(비품) → 자산취득비
- 견적: 추정가격(공급가액, 부가세 뺀 금액) 2천만 원 이하 수의계약은 1인 견적 가능. 학교 지침이 비교 견적을 요구하면 2곳.
- 강사 수당 원천징수: 기타소득은 건당 125,000원 초과 시 8.8%, 사업소득은 3.3%. 서류: 강사 카드(이력), 강의 확인서, 성범죄·아동학대 전력 조회 동의, 지급 내역서.
- 협의회 1인당 상한은 교육청마다 다름(대체로 3만~4만 원 이내).

## 4. 새 품의 화면에 더하는 것

### 4.1 품목 표에 「단위」
- 품목 줄: 품명 · 규격 · **단위** · 수량 · 단가 · 금액. 단위는 자유 입력(빈칸이면 종류별 기본: 물품·행사 「개」, 강사 「시간」, 협의회 「명」).
- 산출 근거 한 줄씩(앱이 만듦): `비커(500ml) 4,500원 × 8개 = 36,000원`.
- [표 복사]는 `품명·규격·단위·수량·단가·금액` 열(탭 구분). 견적서·템플릿·최근 작성에도 단위가 같이 다님(예전 자료는 빈칸).

### 4.2 종류별 계산 도우미 (메모 칸 안, 품목 표 위)
- **물품 구입·행사 운영**: 「단가는 부가세 포함이에요」 체크(기본 켬). 견적 안내 한 줄 — 공급가액(포함이면 합계 ÷ 1.1, 원 아래 버림) 2천만 원 이하면 「1인 견적으로 수의계약할 수 있어요(학교 지침이 비교 견적을 요구하면 2곳)」, 넘으면 「2인 이상 견적·계약 절차 확인」.
- **강사 수당**: 품목 표 머리가 `강사(역할) · 시간 · 시간당 단가`로 바뀜(같은 품목 줄: 품명=강사(역할), 단위 「시간」, 수량=시간, 단가=시간당 단가). 소득 구분 고르기: 기타소득(일시 강의) · 사업소득(계속·반복 강의) · 교직원(기타수당). 줄마다 원천징수(참고)와 실지급액을 보여 줌:
  - 기타소득: 금액 > 125,000원이면 금액의 8.8%(10원 아래 버림), 아니면 0원.
  - 사업소득: 금액의 3.3%(10원 아래 버림).
  - 교직원: 「근로소득으로 행정실에서 계산해요」.
  - 강사 칸에는 「외부 강사 1」처럼 역할만 써도 됨. 강사 이름·주민번호·계좌는 받지 않고, AI에는 강사 칸 글을 보내지 않음(「외부 강사 N명, 모두 X시간」으로만).
- **협의회**: 계산 줄 `인원 [ ]명 × 1인 단가 [ ]원 × 횟수 [ ]회` → [품목에 넣기]로 품목 줄 하나(품명 「협의회 다과비」(고칠 수 있음), 규격 `N명 × M회`, 단위 「명」, 수량 N×M, 단가). 1인 단가가 설정의 「협의회 1인 상한」(기본 40,000원)을 넘으면 확인 목록에 경고.
- **행사 운영**: 품목에 식사·간식·도시락·식비가 있으면 확인 목록에 「행사성 식비는 업무추진비로 따로 품의하는지 행정실 확인」.

### 4.3 예산 과목 도우미 (AI 없음)
- 예산 과목 칸 아래 추천 칩 1~2개 + 「행정실 확인」. 누르면 칸에 들어감(그 뒤 고칠 수 있음).
- 규칙: 협의회 → 업무추진비 · 강사 수당 → 운영수당(외부, 교육강사수당일 수 있음)/기타수당(교직원) · 행사 운영 → 교육운영비(식비가 있으면 업무추진비도) · 물품 구입 → 품명에 교구·실험·재료·교재·체험이 있으면 교육운영비, 소모품·인쇄·사무·토너가 있으면 일반수용비, 단가 30만 원 이상이고 노트북·태블릿·프린터·책상·의자·카메라·TV·모니터 등이면 자산취득비, 모르면 일반수용비·교육운영비 둘 다.
- 지금처럼 비어 있거나 「모르겠어요」면 확인 목록 「예산 과목 · 행정실 확인 필요」.

### 4.4 붙임 서류 체크리스트
- 「지출품의서 1부」는 늘 1번(끌 수 없음). 그 아래 종류별 목록을 체크(기본 체크 ✓):
  - 물품 구입: 견적서 ✓ · 비교 견적서 · 사업자등록증 사본 · 통장 사본
  - 강사 수당: 강사 카드(이력) ✓ · 강의 계획서 · 성범죄·아동학대 전력 조회 동의서 ✓
  - 행사 운영: 행사 계획서 ✓ · 견적서 ✓
  - 협의회: 협의회 계획 ✓ · 참석 예정자 명단
- [+ 붙임 더하기]로 직접 쓰기. 붙임 이름도 개인정보 검사(P-7).
- 강사 수당은 안내 한 줄: 「강의 확인서·지급 내역서는 강의 뒤 지출 때 붙여요. 주민번호·계좌는 행정실에 따로 내요.」

### 4.5 품의 사유(개요) — 기안문 모양
- AI는 지금처럼 **제목과 첫 문장만**. 나머지는 앱이 만듦:
```
{첫 문장: …을(를) 위하여 다음과 같이 …하고자 합니다.}

가. 목적: …
나. 일시: …
다. 대상: …
라. 장소: …
마. 소요 예산: 금75,000원(금칠만오천원)
바. 예산 과목: 교육운영비            (비었으면 줄 없음)
사. 산출 근거: 비커(500ml) 4,500원 × 8개 = 36,000원 외 2건   (3건 이하면 모두, 넘으면 「외 N건」)

붙임  1. 지출품의서 1부.
      2. 견적서 1부.  끝.
```
- 빈 칸 줄은 빼고 남은 줄의 가나다를 다시 매김. 금액 한글 읽기(금칠만오천원)는 앱이 계산.
- 초안을 만든 뒤 붙임·품목을 바꾸면 사유의 앱이 만든 부분(가. 이하)을 다시 맞춤(첫 문장·선생님이 고친 첫 문장은 그대로). 선생님이 사유 칸을 손으로 고쳤으면 다시 맞추지 않고 「품목·붙임이 바뀌었어요 · [사유 다시 맞추기]」.

### 4.6 내려받기
- [한글로 내려받기][▾] (core/doc-export의 exportButton·exportDoc). 문서: 제목, 1. 품의 사유(개요 전체), 2. 산출 내역 표(단위 포함), 산출 근거, 예산 과목, 붙임.

### 4.7 [새로 쓰기]
- 새 품의 머리에 [새로 쓰기]: 지금 품의는 최근 작성에 남고(초안이 있을 때) 빈 품의로.

## 5. 저장한 템플릿 · 최근 작성

### 5.1 저장한 템플릿 (P-8)
- 새 품의 머리 [템플릿으로 저장] → 이름 묻기(기본: 사업명). 저장: 종류·사업명·목적·대상·장소·예산 과목·품목(단위·수량 포함)·소득 구분·붙임 체크.
- 「저장한 템플릿」 탭: 목록(이름 · 종류 · 품목 N개 · 합계 · 저장한 날) + [불러오기] [이름 바꾸기] [지우기]. 지우기는 확인 창.
- 불러오기: 새 품의 칸을 채우고 **일시는 비움**, 초안은 지움 → 새 품의 탭으로. 지금 쓰던 메모에 내용이 있으면 「지금 쓰던 품의를 바꿀까요? (초안이 있으면 최근 작성에 남아요)」.
- 저장: `purchase:templates`(학년도 자료 — 백업에 들어가고, 새 학년도를 시작할 때 가져감), 50개까지.

### 5.2 최근 작성 (P-9)
- [초안 만들기]가 성공할 때마다 그 품의(입력 전체 + 초안)를 맨 앞에 저장. 같은 품의(같은 id)를 다시 만들면 그 자리를 고침. 20개까지.
- 「최근 작성」 탭: 목록(제목 · 종류 · 합계 · 만든 때) + [열기] [지우기]. 열기 → 새 품의로(위 5.1의 바꿀까요 확인과 같음).
- 저장: `purchase:recent`(학년도 자료, 새 학년도에는 가져가지 않음).

## 6. 업무별 AI에 「품의」

- `core/ai-roles.js` TASKS에 `['purchase', '품의']`(5번째). 새 품의 초안 카드 위에 AI 줄. 초안 부르기와 견적서 사진 읽기에 `task: 'purchase'`.
- 검토를 켜면 초안 뒤 검토 AI가 한 번 봄: 보내는 것 = 메인에 보낸 메모(강사 칸 글 제외)와 제목·첫 문장. 살펴볼 것: 메모에 없는 사실, 금액·날짜를 문장에 씀, 종류와 맞지 않는 말(구입/지급/운영), 개인정보. 답 `{ items: [{ field: 'title'|'intro', problem, fix }] }` → 그 칸 아래 두 의견([검토 안 쓰기]/[그대로 두기]), 손으로 고치면 사라짐, 실패는 「검토하지 못했어요」.
- 설정 › AI 「업무별 설정 한눈에」가 5줄이 됨. 저장값 `ai-roles`에 purchase 칸이 없던 예전 값도 그대로 읽힘(기본).

## 7. 설정 › 품의 기준
- 계약 기준 금액(그대로) 아래 「협의회 1인 상한」(원, 기본 40,000). 「교육청·학교마다 달라요(대체로 3만~4만 원). 행정실에 확인해 주세요」. 학년도 자료, 새 학년도에 가져감.

## 8. 지키는 것
- 개인정보: 모든 새 칸(단위·붙임 이름·강사 칸·템플릿 이름)도 주민번호·계좌 모양이면 막음. 강사 칸 글은 AI로 보내지 않음.
- 계산(금액·합계·공급가액·원천징수·한글 금액·산출 근거·붙임 줄)은 모두 앱이 함. AI는 제목·첫 문장만.
- 세율·상한·예산 과목은 모두 「참고용 · 행정실 확인」으로 보여 줌. 앱이 확정하지 않음.
- 예전에 저장한 품의(`purchase:current`, 단위·붙임 없음)도 열림.

## 9. 시험
- 단위: 금액 한글 읽기(0·1·10·100,000·75,000·12,345,678 등), 산출 근거 줄, 공급가액·견적 안내, 원천징수(기타 125,000원 경계·사업 3.3%·10원 버림), 예산 과목 추천 규칙, 붙임 줄(지출품의서 1번·끝.), 사유 조립(빈 줄 빼고 가나다 다시 매김·외 N건), TSV 단위 열, 템플릿·최근 작성 저장 모양과 다듬기, 예전 값 읽기, `isYearKey('purchase:templates')`·carryOver.
- 화면: 강사 수당 계산(줄 금액·원천징수·AI 프롬프트에 강사 칸 글 없음), 협의회 계산 → 품목 줄·상한 경고, 예산 칩 → 칸, 붙임 체크 → 사유·문서, 템플릿 저장·불러오기(일시 비움)·이름 바꾸기·지우기, 최근 작성 저장·열기·지우기·20개, [새로 쓰기], 내려받기 워드·PDF, AI 줄 품의 모델로 요청, 품의 검토 두 의견, 기존 품의 화면 시험 그대로 통과.

## 10. 하지 않는 것
- 에듀파인 자동 입력·연동, 지출(지급) 단계 문서, 원천세 신고, 교육청별 단가표 내장, 강사 이름·주민번호·계좌 받기, 비교 견적서 만들기.
